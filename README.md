# 文件脱敏助手

当前应用版本：**2.0.0-beta.2（独立应用验证版）**。仅在本地开发与验证；用户已删除 Sites 站点，不再发布。历史发布与验证记录见下方验证基线。

一个浏览器本机运行的 AI 文件安全中转工具：先把表格、纯文本或 Word 中需要保护的真实内容替换为任务专属代号，再将 AI 处理后的文件恢复为实名版本。

新任务使用带字段语义的代号，例如 `[[产品名称:P001@7F2A9C4D]]`；字段名称帮助 AI 识别业务角色，短码和任务指纹负责精确还原。旧格式 `[[P001@7F2A9C4D]]` 继续兼容。下载脱敏文件后可一键复制平台无关的 AI 处理说明。

本机新增可选的 **简短替身（试验）**，例如 `产品-K7M4-01`。默认保持现有代号；简短模式需分别保存脱敏文件和还原凭据。还原时导入凭据、核对本机任务并确认文件配套；凭据不是备份，也不能证明 AI 返回文件来源。详细约束见 [简短替身决策](docs/adr/0003-简短替身与独立任务凭据.md)。

> 核心原则：AI 可以知道对象发生了什么，但不需要知道对象真实是谁。

## 当前定位

集中操作记录已有独立本地验证实现，和映射 Vault 分开：默认 `npm run dev` 仍是 5174 本机模式；集中记录测试使用 4175 前端、5180 API、55434 独立 PostgreSQL，仅用虚构身份与数据。运行 `npm run test:operations` 可建立隔离测试库并执行相关验证。企业微信、正式管理员授权及企业部署尚未接通。运行、接口和恢复证据见 [集中记录本地验证](docs/2026-10-28_集中记录本地验证.md)。

当前按 **独立应用** 继续开发，使用 V2 本机映射库。工作台接入已移出计划；现有 Docker 企业构建保留为未完成验收的可选方案，账号、企业微信与集中 Vault 待后续决定。当前仍不承诺任意复杂文件视觉无损或生产稳定。

- 脱敏输入：XLSX、CSV、TXT、MD、DOCX
- 还原输入：XLSX、CSV、TXT、MD、DOCX、PPTX、安全静态 HTML
- 处理位置：浏览器本机
- V2 本机预览：使用独立数据库 `file-masking-assistant-v2-vault`，不读取或迁移 V1 数据
- 企业部署：文件内容仍在浏览器处理，只有映射与任务元数据进入企业内部 Vault
- 安全策略：任务不匹配、未知代号、残缺或被改写代号、以及不支持区域存在代号时停止输出；已知完整代号只是出现次数减少时，显示缺失数量并允许还原仍存在的位置
- 文件上限：CSV、TXT、MD、HTML 为 10 MB；XLSX、DOCX、PPTX 为 20 MB，并在读取文件内容前拦截

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5174/`

- `npm run dev`：开发模式，修改源代码自动更新。
- `npm start`：先构建再启动本地试用版，带安全响应头；修改代码后需停止并重新运行。
- 两种模式仅监听 `127.0.0.1:5174`，不能同时启动；端口占用直接报错，不自动换端口。不要改用 `localhost` 或其他端口，否则看不到原地址保存的映射。
- 本机任务抽屉可检查持久保存状态并主动申请。批准只降低自动清理风险，不是备份；手动清除浏览器数据、隐私窗口或更换浏览器仍可能丢失映射。保留原始文件；本轮不提供明文导出或映射迁移。
- 任务列表的“映射已保存”只表示记录存在；文件检查通过后才确认映射可读取。任务编号重复会拒绝新增，不覆盖旧映射。跨标签页只广播变更通知，不传输映射或凭据。
- 映射及密钥由同一浏览器保存；任务名来自原文件名，任务名称、编号、时间与映射数量等摘要未加密。下载的 JSON 凭据不是映射备份。请避免敏感文件名，并在交给 AI 前复核未选内容、上下文及图片。

## 企业部署

复制 `.env.enterprise.example` 为 `.env.enterprise`，替换数据库密码、HTTPS 访问地址和企业微信配置；数据库密码使用 URL 安全字符。在 `secrets/` 中提供 `wecom_secret.txt`、`session_secret.txt` 和 `vault_master_key.txt`，最后一项为 32 字节主密钥的 Base64 文本。

```bash
docker compose --env-file .env.enterprise up --build
```

`--env-file` 用于 Compose 展开数据库密码；服务级 `env_file` 不能替代它。以上是未验收的历史可选方案，不用于当前本地运行。真实企业部署、企业微信登录和跨设备验收尚未完成，见 [企业版验证门槛](docs/2026-08-25_企业版验证门槛.md)。

## 安全边界

- 文件处理逻辑不主动发送网络请求；部署页面及第三方依赖的供应链安全仍需单独治理。
- CSV 脱敏输出前会扫描全部字段；已建立映射的真实值仍出现在其他列时，不会生成文件或保存无效任务。
- CSV 残留检查覆盖生僻字、emoji、单字名称和短数字。短值不自动做文中替换，遇到残留可原地改选整格替换；表头等不可选区域需先整理原文件。
- CSV 输入和最终输出均检查可能被表格软件执行的公式型文本，不自动改写原值。遇到风险请明确转换为实际结果或普通文本；既有映射含风险值时需从修正后的源文件重建任务。
- CSV 使用有界样本识别分隔符，正式解析过程中限制 20 万行、500 列、500 万字段；每次文件操作只读取一次原文件字节，不跨操作长期缓存敏感源文件。
- 浏览器本机密钥与密文映射都保存在当前浏览器环境，这属于可运行证明，不等同于操作系统密钥库或正式企业密钥管理。
- 图片不做 OCR；图表、SmartArt 和嵌入对象不在已承诺的主动处理范围内。DOCX 脱敏遇到实际批注、脚注/尾注、修订、内容控件或域时会停止生成。
- 真实名称变长可能造成 DOCX/PPTX 换行或溢出，当前只提示，不宣称视觉无损。
- 工程测试通过不等于已经达到生产稳定性；稳定性目标需要真实 AI 来源与累计往返样本验证。
