# 文件脱敏助手

当前应用版本：**2.0.0-beta.1（企业功能验证版）**。本次更新修复 CSV 特殊字符及短值残留漏检、补齐公式风险检查，并优化解析、文件读取与错误恢复说明；不代表已完成真实业务稳定性验收。

一个浏览器本机运行的 AI 文件安全中转工具：先把表格、纯文本或 Word 中需要保护的真实内容替换为任务专属代号，再将 AI 处理后的文件恢复为实名版本。

新任务使用带字段语义的代号，例如 `[[产品名称:P001@7F2A9C4D]]`；字段名称帮助 AI 识别业务角色，短码和任务指纹负责精确还原。旧格式 `[[P001@7F2A9C4D]]` 继续兼容。下载脱敏文件后可一键复制平台无关的 AI 处理说明。

> 核心原则：AI 可以知道对象发生了什么，但不需要知道对象真实是谁。

## 当前定位

当前分支是 **V2 企业功能验证版**。默认开发页面使用独立的 V2 本机映射库；Docker 企业构建才启用集中 Vault。它仍不承诺任意复杂文件视觉无损或生产稳定。

- 脱敏输入：XLSX、CSV、TXT、MD、DOCX
- 还原输入：XLSX、CSV、TXT、MD、DOCX、PPTX、安全静态 HTML
- 处理位置：浏览器本机
- V2 本机预览：使用独立数据库 `file-masking-assistant-v2-vault`，不读取或迁移 V1 数据
- 企业部署：文件内容仍在浏览器处理，只有映射与任务元数据进入企业内部 Vault
- 安全策略：任务不匹配、未知代号、残缺或被改写代号、以及不支持区域存在代号时停止输出；已知完整代号只是出现次数减少时，显示缺失数量并允许还原仍存在的位置
- 文件上限：CSV、TXT、MD、HTML 为 10 MB；XLSX、DOCX、PPTX 为 20 MB，并在读取文件内容前拦截

## 已验证能力

- XLSX 普通单元格、富文本、公式结构和常用样式的脱敏与还原
- CSV 常见分隔符、引号、嵌入换行、UTF-8/BOM 与 GB18030 输入
- TXT/MD 明确标签与 Markdown 表格候选、手动补充、UTF-8/BOM 和 CRLF/LF 往返
- DOCX 正文、表格、页眉页脚、文本框与跨文本片段的脱敏和还原
- PPTX 幻灯片文字、表格、备注与跨文本片段代号还原
- HTML 可见文本和描述属性还原，并移除脚本、表单、框架、远程资源及事件处理器
- 深色/浅色/系统主题，以及桌面、手机竖屏和手机横屏的紧凑任务布局

完整边界与最新证据见 [项目现状与验证基线](docs/2026-08-19_项目现状与验证基线.md)。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5174/`

## 企业部署

复制 `.env.enterprise.example` 为 `.env.enterprise`，在 `secrets/` 中提供企业微信密钥、会话密钥和 32 字节主密钥的 Base64 文本，再运行 `docker compose up --build`。企业模式只开放本人任务，映射默认保留 30 天；审计日志不记录真实值或文件内容。

## 安全边界

- 文件处理逻辑不主动发送网络请求；部署页面及第三方依赖的供应链安全仍需单独治理。
- CSV 脱敏输出前会扫描全部字段；已建立映射的真实值仍出现在其他列时，不会生成文件或保存无效任务。
- CSV 残留检查覆盖生僻字、emoji、单字名称和短数字。短值不自动做文中替换，遇到残留可原地改选整格替换；表头等不可选区域需先整理原文件。
- CSV 输入和最终输出均检查可能被表格软件执行的公式型文本，不自动改写原值。遇到风险请明确转换为实际结果或普通文本；既有映射含风险值时需从修正后的源文件重建任务。
- CSV 使用有界样本识别分隔符，正式解析过程中限制 20 万行、500 列、500 万字段；每次文件操作只读取一次原文件字节，不跨操作长期缓存敏感源文件。
- 浏览器本机密钥与密文映射都保存在当前浏览器环境，这属于可运行证明，不等同于操作系统密钥库或正式企业密钥管理。
- 图片不做 OCR；图表、SmartArt 和嵌入对象不在已承诺的主动处理范围内。DOCX 脱敏遇到实际批注、脚注/尾注、修订、内容控件或域时会停止生成。
- 真实名称变长可能造成 DOCX/PPTX 换行或溢出，当前只提示，不宣称视觉无损。
- 工程测试通过不等于已经达到生产稳定性；稳定性目标需要真实 AI 来源与累计往返样本验证。
