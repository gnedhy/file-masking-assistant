# 文件脱敏助手

一个浏览器本机运行的 AI 文件安全中转工具：先把表格、纯文本或 Word 中需要保护的真实内容替换为任务专属代号，再将 AI 处理后的文件恢复为实名版本。

> 核心原则：AI 可以知道对象发生了什么，但不需要知道对象真实是谁。

## 当前定位

当前版本是**功能验证版**，不是正式企业 Token Vault，也不承诺任意复杂文件视觉无损。

- 脱敏输入：XLSX、CSV、TXT、MD、DOCX
- 还原输入：XLSX、CSV、TXT、MD、DOCX、PPTX、安全静态 HTML
- 处理位置：浏览器本机
- 本机映射：使用任务指纹隔离，并以浏览器本机密钥加密保存
- 安全策略：任务不匹配、未知代号、残缺代号或不支持区域存在代号时停止输出；仅安全静态 HTML 允许对完整代号受控还原，并把被改写代号原样保留为明确的“部分还原”

## 已验证能力

- XLSX 普通单元格、富文本、公式结构和常用样式的脱敏与还原
- CSV 常见分隔符、引号、嵌入换行、UTF-8/BOM 与 GB18030 输入
- TXT/MD 明确标签与 Markdown 表格候选、手动补充、UTF-8/BOM 和 CRLF/LF 往返
- DOCX 正文、表格、页眉页脚、文本框与跨文本片段的脱敏和还原
- PPTX 幻灯片文字、表格、备注与跨文本片段代号还原
- HTML 可见文本和描述属性还原，并移除脚本、表单、框架、远程资源及事件处理器
- 深色/浅色/系统主题，以及桌面、手机竖屏和手机横屏的紧凑任务布局

完整边界与最新证据见 [项目现状与验证基线](docs/2026-08-19_项目现状与验证基线.md)。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5173/`

```bash
npm run test:xlsx
npm run test:xlsx-package
npm run test:csv
npm run test
npm run test:e2e
npm run test:fixtures
npm run test:office
npm run test:html
npm run test:sites

```

`npm test` 会在 `tests/output/validation-assets` 自动生成合成的跨格式样本，不依赖桌面目录、固定外部文件或企业真实数据。

## 安全边界

- 文件处理逻辑不主动发送网络请求；部署页面及第三方依赖的供应链安全仍需单独治理。
- 浏览器本机密钥与密文映射都保存在当前浏览器环境，这属于可运行证明，不等同于操作系统密钥库或正式企业密钥管理。
- 图片不做 OCR；图表、SmartArt 和嵌入对象不在已承诺的主动处理范围内。DOCX 脱敏遇到实际批注、脚注/尾注、修订、内容控件或域时会停止生成。
- 真实名称变长可能造成 DOCX/PPTX 换行或溢出，当前只提示，不宣称视觉无损。
- 工程测试通过不等于已经达到生产稳定性；稳定性目标需要真实 AI 来源与累计往返样本验证。
