# 文件脱敏助手

当前应用版本：**2.0.0-beta.2**。项目类型：Web 应用（React + Vite 前端，Node.js + PostgreSQL 服务端），部署在公司内部，用企业微信登录。

一个 AI 文件安全中转工具：先把表格、纯文本或 Word 中需要保护的真实内容替换为简短代号（如 `产品-K7M4-01`），再将 AI 处理后的文件恢复为实名版本。**文件只在浏览器内处理，不上传**；只有加密后的还原记录和操作记录保存到公司服务器，所以登录同一企业微信账号即可在任意电脑还原自己的文件。

> 核心原则：AI 可以知道对象发生了什么，但不需要知道对象真实是谁。

当前架构和取舍见 [ADR 0005：企业单一部署与固定简短代号](docs/adr/0005-企业单一部署与固定简短代号.md)，术语见 [CONTEXT.md](CONTEXT.md)，部署步骤见 [部署指南](docs/部署指南.md)。

## 当前状态

- 2026-11-02 起只保留企业部署：本机模式、浏览器内还原记录、明文备份和还原钥匙文件已删除。
- 新任务固定使用简短代号；还原时按 4 位任务编号自动找到本人任务，旧的 `[[产品名称:P001@7F2A9C4D]]` 格式仍能还原。
- 还原记录不自动到期，用户可在“我的任务”中删除；操作记录保留 180 天。
- 已在本机 PostgreSQL 上以生产方式启动验证；真实企业微信登录要等应用信息和域名就绪后验收。
- 简短代号的外部 AI 保留率对比（ADR 0003 的准入要求）尚未完成。

## 支持范围

- 脱敏输入：XLSX、CSV、TXT、MD、DOCX
- 还原输入：XLSX、CSV、TXT、MD、DOCX、PPTX、安全静态 HTML
- 文件上限：CSV、TXT、MD、HTML 为 10 MB；XLSX、DOCX、PPTX 为 20 MB，在读取文件内容前拦截
- 安全策略：任务不匹配、未知代号、残缺或被改写代号、以及不支持区域存在代号时停止输出；已知完整代号只是出现次数减少时，显示缺失数量并允许还原其余位置

## 本地开发

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5174/`。`npm run dev` 启动 `scripts/dev-server.mjs`：一个进程里同时提供开发用接口和 Vite 页面，修改源代码自动更新。

- 默认使用内存存储，重启后数据清空；每个新浏览器自动分配一个独立的测试身份。
- 设置 `DATABASE_URL` 可改用 PostgreSQL；`npm run operations:db` 会启动隔离的本地测试库（端口 55434）。
- 固定测试身份可通过 `POST /__test/session`（`{"user":"admin"|"alice"|"bob"}`）切换。开发服务和测试身份不会进入生产镜像。

## 部署

```bash
cp .env.enterprise.example .env.enterprise   # 填写访问地址、企业微信信息和管理员名单
docker compose --env-file .env.enterprise up -d --build
```

完整步骤（密钥生成、HTTPS 反向代理、验收、备份与回滚）见 [部署指南](docs/部署指南.md)。生产入口是 `server/index.mjs`（`npm start`），健康检查为 `/healthz`、`/readyz`。

## 主要目录

- `src/`：React 界面和浏览器内文件处理；`vaultStore.js`、`session.js` 负责与服务器通信。
- `server/`：生产服务。`handler.mjs` 合并还原记录（`app.mjs`）和操作记录（`operations-app.mjs`）接口，`session.mjs` 处理企业微信登录。
- `scripts/dev-server.mjs`：开发与测试服务。
- `tests/`：单元测试、浏览器测试和合成样本；`tests/output/` 为可再生输出。
- `docs/`：设计记录（`adr/`）、部署指南和验证记录。

## 安全边界

- 文件内容不离开浏览器；还原记录（代号与真实值的对应关系）由服务器用每任务独立数据密钥加密保存，主密钥由 Docker Secret 提供。
- 数据库和主密钥是高敏感资产，必须分开备份；主密钥丢失后还原记录不可恢复。
- 未登录或服务器不可用时，脱敏和还原都会停止，不会生成无法还原的文件。
- 每个用户只能读取自己的还原记录和操作记录；管理员（`ADMIN_USER_IDS`）只多出查看全部操作记录的权限。
- 还原别人的文件时，只有在 4 位编号恰好与本人任务相同、且代号都能对上时才可能还原出错误内容；页面会显示匹配到的任务名供核对。
- CSV 输入和输出都检查可能被表格软件执行的公式型文本，不自动改写原值。
- 图片不做 OCR；图表、SmartArt 和嵌入对象不在主动处理范围内。DOCX 遇到批注、脚注、修订、内容控件或域时会停止生成。
- 真实名称变长可能造成 DOCX/PPTX 换行或溢出，当前只提示，不宣称视觉无损。
