# ADR-0002：企业集中 Vault 与版本隔离

## 状态

已采纳

## 决策

- V1.1 以 `v1.1.0-local` 冻结，V2 仅在独立 worktree、分支、端口、浏览器数据库和站点中开发。
- 文件内容始终留在浏览器本机；企业服务只接收任务映射和必要元数据。
- 企业微信工作台提供用户身份；首版只允许本人跨设备访问，不提供部门共享或审批后台。
- 企业映射默认保留 30 天，使用每任务独立 AES-256-GCM 数据密钥加密，主密钥由 Docker Secret 提供。
- V1.1 本机映射不自动迁移到 V2。

## 结果

- V2 的安全修复和企业能力不会覆盖 V1.1 的代码、站点或浏览器数据。
- 企业 Vault 属于企业边界的一部分，但仍不得向外部 AI 提供真实映射。
