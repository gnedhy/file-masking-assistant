# ADR-0001：本机任务隔离与失败关闭

## 状态

已采纳

## 背景

普通字段映射可以隐藏真实值，但在文件经过外部 AI 改写、跨格式生成或多次处理后，容易出现跨任务混用、未知代号被误替换和部分还原。产品需要在保持低学习成本的同时，避免“看起来还原成功但内容已经错配”。

## 决策

- 每次脱敏创建独立任务，正式代号必须携带任务指纹。
- 真实值与正式代号的映射只保留在本机任务中，不提供给外部 AI。
- 还原只接受完整且能由当前本机映射确认的正式代号。
- 任务不匹配、未知正式代号、危险区域代号或还原后新增残留代号均失败关闭。
- XLSX、CSV、TXT、MD、DOCX、PPTX 和安全静态 HTML 遇到残缺或被改写的代号时均失败关闭。已知完整代号只是出现次数减少时，显示缺失数量并允许还原仍存在的位置；不把改写代号原样留在可下载文件中。
- 当前浏览器本机存储只称为功能验证，不称为正式企业 Token Vault。

## 结果

2026-09-05 校准：以上规则与现行 V2 语义代号方案一致，取代旧版允许 HTML 保留改写代号的例外；冻结 V1.1 不修改。

- 用户必须在保有对应本机任务的设备和浏览器中还原。
- AI 删除代号或把内容转成图片时，工具不猜测、不 OCR。
- 产品牺牲部分“尽量输出”的便利性，换取可解释、可核对的还原边界。
