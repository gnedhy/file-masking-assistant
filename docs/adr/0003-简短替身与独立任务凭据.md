# 简短替身与独立任务凭据

日期：2026-10-27。状态：部分被 [ADR 0005](0005-企业单一部署与固定简短代号.md) 取代（还原凭据与企业模式限制已废止，简短代号成为默认）。

## 决策

- 新任务可选 `客户/产品/人员/信息-四位标记-序号`。序号至少两位，超过 99 继续增长；同类别、同原值复用。
- 四位标记字符集为 `23456789ABCDEFGHJKLMNPQRSTUVWXYZ`，共 32 个字符。它只是匹配提示，不是完整任务 ID、安全密钥或来源证明。
- 内部任务使用完整 UUID。现有 V2 IndexedDB 从版本 1 增量升到 2，仅新增 `markers` 占用表；不重写旧任务密文或旧密钥。
- 标记用唯一键写事务占用，随机碰撞最多重试 256 次。失败任务和已删除任务的占用仍保留。原文包含同标记序列时重新占用；保守预检不复用被放弃的标记。
- 凭据仅保存版本、UUID、标记、128 位随机核验值，最高 16 KiB；核验值同时位于加密本机任务中。凭据不是映射备份。
- 所有格式使用统一解析结果；扫描阶段的 `short:标记` 仅用于分组，禁止作为 Vault 查询 ID。只有验证凭据后才查询其 UUID。
- 简短还原必须核验凭据、本机映射、完整替身，并由用户确认配套任务；输出前重复核验。新旧混合、未知完整替身、其他标记、可识别改写和危险区域代号失败关闭。
- 已知替身缺失提示但允许还原其余位置；无有效替身停止。企业模式不开放新格式，也不将新任务发送至企业服务。

## 必须保留的风险说明

独立数据库可能产生相同标记和替身；清除浏览器数据也会清除占用记录。若拿错凭据且文件中的完整替身恰好相同，工具无法自动证明来源不同，可能按选定任务还原。用户配对确认是必要的人为核对，不是密码学来源认证。

AI 把替身改成普通文字，或改成同任务另一个有效替身时，无法保证识别。凭据、四位标记、缺失统计均不能恢复已删除信息。图片不做 OCR。

## 接口

- `createSafeFile(file, selection, { tokenFormat: "short" })`；省略选项保持旧格式。
- `inspectRestoreFile(file, { credential })`。
- `restoreSafeFile(file, taskId, { credential, pairingConfirmed: true })`。
- `readTaskCredential(file)` 在读取前检查尺寸，再严格核对结构。
- 生成结果中的 `credential` 是下载对象，不含映射；`aliases` 仅列出替身。

## 准入

工程验证与外部 AI 保留率分别记录。至少三个 AI 来源的虚构样本对比未完成前，简短模式始终标注试验且非默认。当前仅本地修改和验证，不推送、不发布、不新增企业接入。
