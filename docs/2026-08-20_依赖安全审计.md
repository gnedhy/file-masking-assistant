# 2026-08-20 依赖安全审计

## 门槛

- CI 必须执行 `npm run audit:prod`。
- 生产或开发依赖出现中等级及以上告警时失败。

## 当前结果

- DOMPurify 已升级至 3.4.14，当前已知告警清除。
- ExcelJS 继续使用 4.4.0，并将其间接 UUID 固定至已修复的 11.1.1；XLSX 测试与生产构建通过。
- `browserslist` 依赖链已定向更新至无已知告警版本。
- PPTX 基准文件改为仓库内的合成测试资产，验证脚本不再依赖 `pptxgenjs → image-size`。
- `npm audit --audit-level=moderate`：0 项中等级、高等级或严重告警。

## 处理说明

`image-size` 当前没有修复版本，因此没有采用破坏性降级或审计例外。PPTX 测试样本仍可由一条命令复制并生成异常变体，且不进入产品运行依赖。每次依赖更新仍需重新执行全量审计。
