# 2026-08-20 依赖安全审计

## 门槛

- CI 必须执行 `npm run audit:prod`。
- 生产依赖出现中等级及以上告警时失败。
- 开发依赖告警必须记录用途、可利用边界和升级条件，不能用破坏性降级掩盖。

## 当前结果

- DOMPurify 已升级至 3.4.14，当前已知告警清除。
- ExcelJS 继续使用 4.4.0，并将其间接 UUID 固定至已修复的 11.1.1；XLSX 测试与生产构建通过。
- `npm audit --omit=dev`：0 项告警。
- 全量审计仍报告 PPTX 测试样本生成依赖 `pptxgenjs → image-size` 的 2 项高等级拒绝服务告警。

## 开发依赖例外

`pptxgenjs` 只在本地合成验证资产脚本中运行，不进入浏览器生产包，也不读取用户上传的 ICNS、JXL 或 HEIF 图片。当前上游 `image-size` 尚无安全版本，审计建议的 PPTXGenJS 1.1.5 属于破坏性降级，因此暂不采用。

解除例外的条件：PPTXGenJS 发布不再依赖受影响版本的更新，或验证资产生成器改为不经过该解析链。每次依赖更新仍需重新执行全量审计。
