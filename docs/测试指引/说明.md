# 测试期指引（一页纸）

给测试同事的两张单页指引，可直接发群或打印（A4）。

| 文件 | 内容 |
|---|---|
| `使用指引.png` / `.pdf` | 3 个阶段、5 个步骤：脱敏 → 交给 AI → 还原，附注意事项 |
| `反馈指引.png` / `.pdf` | 两个反馈入口：结果页「不满意」、右上角「反馈」，以及回复在哪里看 |

## 群发文案

> 测试阶段难免有小问题，欢迎随时反馈。有两个入口：
>
> **1. 结果不对：点结果页下方的「不满意」**
> 脱敏或还原完成后，结果页底部会问“这次结果满意吗？”。
> - 结果没问题，点**满意**，帮我们了解哪些文件处理得好。
> - 有漏替换、还原不全等问题，点**不满意**，写下问题后发送。系统会自动附上本次检查结果和脱敏版文件（只含代号）；原文件和还原后的文件含真实信息，不会发送。
>
> **2. 报错、卡住或有功能建议：点右上角的「反馈」**
> 处理过程中报错、没出结果，或者想提新需求，都可以从这里提交。
>
> 管理员处理后会回复到右上角的「反馈」里，有新回复时按钮上会出现红色数字。
>
> 填写时请不要写客户名称、金额等真实信息，写列名或位置即可。

## 素材与重新生成

- `截图/`：在本地开发服务上用普通员工身份（alice）走完整流程截取，全部是测试数据，1440 宽、2 倍清晰度。
- `guide.css` / `guide.js`：共用样式和截图裁剪标注。每张截图在 HTML 里用 `data-crop`（裁剪区域）和 `data-marks`（红框位置）描述，坐标是 1440 宽页面的 CSS 像素。
- 界面改版后：重新截图，替换 `截图/` 里同名文件，必要时调整坐标，然后运行：

```bash
node docs/测试指引/render.mjs
```

会重新生成两张 PNG（2480×3508）和 PDF，并提示是否超出一页 A4。

## 应用内「使用指南」

顶栏「使用指南」面板里的截图，就是从这两份指引里按红框标注裁出来的小图（`public/guide/*.jpg`，每张 10–50 KB）。截图或标注改了以后，再运行一次：

```bash
node scripts/build-guide-images.mjs
```

面板里的文字在 `src/GuideDrawer.jsx`，改指引文字时两边一起改。
