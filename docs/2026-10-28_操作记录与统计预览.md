# 操作记录与使用统计预览

## 已实现（仅本地）

入口改为“操作记录”，未登录状态明确标为本机记录。新增输入/输出文件名、独立导入事件、筛选搜索和 UTF-8 BOM CSV 导出。下载与导出记录均只声明已发起。旧记录不补造文件名，现有映射数据库和任务不迁移。

文件名仅取 basename，最长 512 个字符，剔除控制字符；不保存路径、正文、映射、凭据内容或原始错误。首次非阻断提示可关闭。当前本机仍仅保留最近 500 条，不保证 180 天保留或防篡改。

管理员使用统计为开发环境设计预览，样本完全虚构，未读取真实任务。按时间、用户、格式、结果筛选；任务按用户及任务 ID 去重，导入与内部复检分开，下载请求与记录导出分开。还原结果包括完整、部分和内容缺失，明细明确区分。支持示例 CSV 导出，导出内容带“虚构示例”。返回文件处理保留已有选择。

## 后续企业接入契约（未实现）

### 本轮界面收尾

保留既有风格，将统计筛选、指标、用户汇总和明细分区；移动端指标采用两列，主题颜色复用已有变量。操作记录整合数量与导出工具栏，将保存限制折叠，凭据和映射动作不再显示无意义的空文件名。文件名展开直接显示完整名称，不重复追加同一文本。

新增文件名展开断言后，统计工作流在 Chromium、Firefox、WebKit、390px 共 4 项通过，包含三种主题、筛选导出和返回保留选择；生产构建通过。查看桌面浅色及移动深色截图。未改动处理引擎与用户映射；现有构建大包警告仍保留。

身份由企业认证服务提供，服务端校验普通用户仅本人、管理员全部。集中事件应有独立事件 ID 去重和完整任务 ID，客户端短标记只作显示。文件名属于可能敏感的元数据，须提前告知；企业记录保留 180 天，与映射到期和删除分离。断网暂存、补传保持原用户归属并显示未同步状态，不能把缺报算作未使用。

统计服务与集中映射 Vault 解耦：接入身份和记录不自动上传文件或映射，不迁移现有本机任务。企业微信登录、集中记录接口、真实管理员授权及清理策略需下一阶段单独实施。
