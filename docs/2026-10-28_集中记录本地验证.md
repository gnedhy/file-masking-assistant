## 隔离 PostgreSQL

运行 `node scripts/operations-local.mjs start`。工具只使用 PostgreSQL 程序，数据位于忽略目录 `tests/output/operations-pg`，监听 `127.0.0.1:55434`，库名 `filemask_operations_test`。不连接现有 HonghaoPostgreSQL18 实例。`OPERATIONS_PG_BIN` 可以指定程序目录。

本地虚构数据集群采用 trust 认证，只用于隔离开发，不可作为企业部署配置。真实部署必须使用密码/Secret、受限数据库角色和内网访问控制。

`status` 检查实例；`stop` 仅停止该数据目录对应实例；`backup` 生成该库备份；`restore-check` 恢复到新时间戳数据库，不覆盖原库，恢复库保留供检查。

## 运行与接口

`npm run test:operations` 使用隔离数据库，运行后端/性能测试和四浏览器测试；测试服务仅监听本机。单独启动 API 使用 `node --env-file=.env.operations server/operations-index.mjs`，配置从 `.env.operations.example` 复制并填写两个独立随机 Secret（各至少32字节）。前端设置 `VITE_OPERATIONS_ENABLED=true` 后运行 `npm run dev -- --port 4175`。不得在原5174来源启用测试身份。

测试会话只能以 POST `/__test/session`、可信 Origin 与 `x-test-secret` 建立，body为 `{ "user": "alice" }`（另有bob/admin）。页面不提供身份切换按钮；测试登录不是企业登录。关闭测试开关后此入口404，当前尚无正式登录方式。

接口：GET `/api/v1/session`；POST `/api/v1/operation-events/batch`；GET `/api/v1/operation-events` 与 `/api/v1/operation-statistics`；POST `/api/v1/operation-events/export`（为留导出记录且执行CSRF校验，采用POST）。筛选共用from/to/user/format/result/action/query；分页每页10条。导出全量筛选结果，CSV包含筛选范围并防公式注入。

事件仅接受版本、独立事件UUID、操作关联UUID、发生时间、动作、结果、任务ID/标记、格式、输入/输出basename；用户和接收时间由服务端确定。旧八位任务ID和新UUID均支持。重复事件只确认，不重复累计；同ID不同内容拒绝。

## 数据与故障边界

服务仅初始化operation_events和迁移版本表，Vault接口404，无映射主密钥依赖。默认本机模式不发送记录请求；已有500条本机历史不迁移。已确认身份的新事件进入独立IndexedDB队列，最大5000条/10MiB，按身份隔离。确认后删除、拒绝后停止自动重试，断网退避补传；关闭浏览器后不保证后台上传。超限/配额失败提示记录可能缺失，不阻断文件处理。不同用户的待同步项不会归到当前用户。

补传队列3个核心场景×4浏览器共12项通过；WebKit容量样本建立较慢，改为owner/status索引与字节元数据后完成验证。最后的持久缺报提示修正及10MiB边界另在Chromium4项通过；10MiB采用元数据边界注入，非实际累积文件。默认关闭零API/历史不迁移1项通过；旧本机记录与预览桌面/390px共8项回归通过。最新索引版真实数据库闭环四浏览器重新通过，包含10条分页及筛选回第一页。生产构建通过，已有大包警告仍在。
