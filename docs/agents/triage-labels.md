# Triage labels

| 工作流角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者判断 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格和验收条件完整，可直接实施 |
| `ready-for-human` | `ready-for-human` | 需要业务决策或人工验收 |
| `wontfix` | `wontfix` | 已决定不处理 |
